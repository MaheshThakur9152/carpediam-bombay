# Carpediam Bombay

Luxury fine jewelry & bespoke storefront built with React 19, TypeScript, Vite, and Tailwind CSS.

## Features
- Dynamic responsive header with transparent overlay over hero video
- Video hero showcase with custom audio/video controls
- Product category listings with sort & material/collection filters
- Product detail pages with metal & size variant selectors
- Interactive shopping bag drawer with live cart calculations
- Full-screen search overlay with live product search
- Wishlist functionality with persistent state
- Responsive mobile menu drawer and layouts

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Production build
npm run build
```
